# Geração dos documentos

- `equipe.json`: nomes, RMs, turma e links (GitHub, deploy, vídeo). **Preencha e rode `python build_all.py`** para atualizar todos os PDFs de uma vez.
- `doc_agile.py`, `doc_database.py`, `doc_ddd.py`: conteúdo de cada PDF.
- `gen_erd.py`: diagrama relacional a partir do DDL · `gen_uml.py`: diagramas de classes a partir do código Java · `img/casos_de_uso.puml`: casos de uso.
